# design_case

케이스 피드 템플릿 — 전후 사진 넣고 문구만 적으면 끝.

feed_temp(브랜딩 피드 템플릿)와 같은 구조의 한 파일 도구입니다. 사진은 브라우저 안에서만 처리되고 서버로 올라가지 않습니다.

열면 **디자인 프리셋** 화면이 먼저 뜹니다. 표지를 누르면 그 캐러셀 전체가 펼쳐지고, '이 프리셋으로 시작'을 누르면 편집 화면으로 들어갑니다. '내 사진으로 미리보기'에 역할별 사진을 한 번 넣으면 모든 프리셋 썸네일에 들어갑니다.

템플릿 53종
- 내 패턴: 한 줄 캐러셀(여섯 장이 한 장처럼 이어짐)
- 3D 오브제: 로고 오브제(명판·명함·잔상 판·탁상 거울, SONGSHOP/HOSOO STUDIO) · 기호 오브제(물음표·느낌표·체크·말풍선·따옴표) · 정보 오브제(결 가닥·물방울·덤벨) · 입체 숫자·글자 · 펜슬·자·스풀리 · 휴대폰 목업(캡처가 없으면 로고 화면)
  - 손님 사진은 3D 물체에 붙이지 않습니다(어색해 보여서). 사진 겹쳐 놓기·전시 무대는 목록에서 뺐고, 예전 작업을 열 때만 그대로 보입니다.
- 새 제안: 두 굵기 표지 · 심리스 반반 · 심리스 위아래 · 브로우 인덱스 · 디도 표지·사진 띠 · 스며드는 정보 카드 · 케이스 파일 · 원장의 문장 · 끝 장 · 아웃트로
- 케이스 · 전후: 표지 · BEFORE · AFTER · DETAIL · 좌우 전후 · 케이스 리포트 · 원형 전후(단계 점) · 원형 돋보기
- 후기: 손님 한마디 · 직후 사진 + 손님 말 · 소감 카드 · CUSTOMER REVIEW 표지(영문 디도) · 후기 캡처 콜라주 · 사진 격자 콜라주
- 질문 · 정보: 질문 표지 · 정보 표지 · 고민 캡처 카드 · 정보 카드 · 비교 카드 · 좌우 비교 + 흰 띠 · 문장 카드 · STEP 과정 카드
- 공지 · 마무리: 공지·이벤트 표지 · 고민 01~04 · 카카오 채널 검색 안내 · QR 카드 · 연락처
- 브랜드 포스터: 화보 표지 · 잔상 워드마크 · 세리프 문구 · 잡지 표지형 · 액자형 · 행사·오픈 포스터 · 실루엣 티저 · 룩북 지면 · 사진만

기능
- 크기 3:4(1080×1440) · 4:5(1080×1350), 글꼴 프리텐다드 · 페이퍼로지
- 한 장에 사진 여러 칸(위아래·인셋·좌우·격자), 미리보기에서 누른 칸을 끌어서 위치 조정
- 문구에서 `**굵게**` 로 감싸면 그 부분만 굵어집니다
- 글자 칸에 `SONGSHOP`이나 `HOSOO STUDIO`라고 쓰면 결과형 영상 아웃트로와 같은 워드마크(잔상 두 겹 + 아래 작은 글)로 그려지고, '끝 장 · 아웃트로'는 상담·예약 문의 + 카톡·인스타 아이콘까지 영상 마무리 카드와 같은 구성입니다. 이름 칸은 `**hosoo** 검색`처럼 일부만 굵게 쓸 수 있습니다
- 케이스 파일 표지 제목에 숫자 대신 케이스 이름(예: 잔흔 **커버**)을 쓰면 번호 대신 한글 두 굵기로 그려집니다
- 사진 처리: 흑백 · 실루엣 · 흐림 · 잔상, 사진끼리 경계 없이 섞기
- 3D 오브제: 재질(먹 유광 · 미색 도자기 · 반무광 유리) · 돌리기 · 크기는 효과 탭 '입체', 물체는 미리보기에서 끌어 옮김. 정보 오브제는 글 내용과 이어지는 물체를 고릅니다(결 사이 여백 = 결 가닥, 지성 피부 = 물방울, 운동·땀 = 덤벨)
  - 3D 엔진(three.js)을 인터넷에서 받아 오므로 처음 열 때 1~2초 걸립니다. 인터넷이 끊기면 3D 자리에 안내 문구가 나옵니다.
  - 큰 그림은 경로 추적(three-gpu-pathtracer)으로 실제 빛처럼 부드러운 그림자·반사를 그립니다. 편집 중에는 빠른 그림이 먼저 보이고 10~30초 뒤 고화질로 바뀌며, 저장은 고화질이 끝난 뒤에 됩니다. 로고는 입체로 돌출하지 않고 면에 새김(음각)·인쇄로 입힙니다. 잔상 판(반투명 판)은 경로 추적에서 GPU가 멈춰 빠른 그림으로만 그립니다.
